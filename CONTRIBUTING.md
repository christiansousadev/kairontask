# Contributing to KaironTask

Thank you for your interest in contributing to **KaironTask**!

If you want to discuss something privately, please reach out to support@kairontask.app.

### Code of Conduct

Be respectful, constructive, and collaborative with all community members and contributors.

### How to Contribute

1. **Bug Reports & Feature Requests**: Submit issues via the [GitHub Issues](https://github.com/christiansousadev/kairontask/issues) tracker.
2. **Pull Requests**:
   - Please follow the Angular commit message format (`type(scope): description`).
   - Run `npm run checkFile <file>` on modified files before committing.
   - Run `npm test` to ensure all tests pass.
3. **Spread the Word**: Share KaironTask with colleagues and teams looking for a sovereign, Local-First task and time management solution.
